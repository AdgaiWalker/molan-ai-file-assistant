## 当前一致的主线

- 手机端：收集微信 / QQ / 本地散落的 Markdown、JSON、Office 文件，先阅读，再复制、编辑、转换、分享，最终沉淀为 AI 可读取资源。
- 电脑端：以 CLI / 脚本转换为主，把 Word、PDF、PPT、Excel 等转成 Markdown / JSON，让 AI / agent 能稳定读取。
- 云端：不是网盘；只在用户主动保存时同步，用来连接手机、电脑和 AI 工具。
- 提示词：不只是文件附属功能，而是手机端 AI 工具使用场景里的快速复制、组合和同步系统。
