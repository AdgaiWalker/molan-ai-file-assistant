# 墨览关键指标设计

版本：v1  
日期：2026-07-04  
对应任务：D0.4  
依据：`PRD.md §十四`、`PRD.md §十五`、`TODO.md §17`、`TODO.md §19.2`

## 1. 指标分层

| 层级 | 指标目标 | 为什么重要 |
|---|---|---|
| 入口指标 | 微信 / QQ 中 1-2 次滑动找到墨览，5 秒内看到内容 | 入口失败则产品不成立 |
| 复制指标 | 打开文档到复制提示词 10 秒内 | 复制是手机端最高频动作 |
| 分享指标 | 打开文档到转换并分享 20 秒内 | 办公转发闭环必须短 |
| 稳定指标 | Markdown / JSON 长文、大文件、离线可用 | 保证真实文件不崩 |
| 转换指标 | CLI 输出 Markdown + AI 可读 JSON 日志 | 支撑电脑端 AI 工作流 |
| 云同步指标 | 用户主动同步后能跨设备找回 | V2 的信任基础 |
| AI 可读指标 | AI 可读取、引用、写回 Markdown / JSON | 证明墨览不是普通阅读器 |

## 3. 性能与包体指标

| 指标 | V1 目标 | 测量方式 | 证据 |
|---|---:|---|---|
| Android debug APK 大小 | 记录基线，不设硬门槛 | 构建后读取文件大小 | 文件名、大小、SHA256 |
| Android release arm64 APK 大小 | 优先低于 universal APK，记录基线 | release 构建 | 文件名、大小、SHA256 |
| Android AAB 大小 | 记录基线，用于商店分发 | release 构建 | 文件名、大小、SHA256 |
| 冷启动到首页 | 记录基线，目标 5 秒内到可操作 | Android Studio / 真机录屏 | 设备、系统、耗时 |
| 外部文件冷启动到阅读 | 目标 5 秒内 | 微信 / QQ / 文件管理器真机录屏 | 来源 App、耗时 |
| 1MB+ Markdown 滚动 | 不白屏、不明显卡死 | 真机手动滚动 | 样例文件、机型、结果 |
| 大 JSON 展开 / 搜索 | 不一次性展开导致卡死 | 真机或模拟器手动测 | 样例大小、耗时、结果 |
| 当前文件转换耗时 | 记录基线，目标 20 秒内分享 | Markdown -> PDF / Word 各测 | 样例、耗时、输出文件 |

## 4. 电脑 CLI 指标

| 指标 | 目标 | 测量方式 | 证据 |
|---|---|---|---|
| `molan check` | 能识别 pandoc 可用性并返回结构化结果 | CLI 执行 | 命令、退出码、输出 |
| 单文件转换 | docx/pdf/pptx/xlsx/csv 至少各有真实样例 smoke | CLI 执行 | 输入、输出 Markdown、JSON 日志 |
| 批量转换 | 成功/失败隔离，不因单个文件失败中断全部 | fixture 目录 | 结果列表、错误码 |
| JSON 输出契约 | 保留 `ok/results/outputPath/errorCode/error` | Vitest / smoke | 测试结果 |
| 非 0 退出码 | 失败命令返回非 0 | 人工或测试 | 命令、退出码 |

## 5. V2 云同步指标

| 指标 | 目标 | 测量方式 | 证据 |
|---|---|---|---|
| 云同步成功率 | 记录基线，目标逐步达到 99% | 本地日志 / 后端日志 | requestId、设备、结果 |
| 主动上传确认率 | 每次文件内容上传前都有用户确认 | UI 验收 | 截图 / 测试步骤 |
| 冲突保留率 | 多端冲突不覆盖旧版本 | 双设备或模拟测试 | 两个版本均存在 |
| 删除完成度 | 删除云端数据后不可再拉取 | API / 客户端验收 | 请求和响应记录 |
| 跨设备恢复 | 新设备登录后恢复提示词和最近文档 | 真机 / 模拟器 | 设备、账号、恢复结果 |

## 6. AI 可读取指标

| 指标 | 目标 | 测量方式 | 证据 |
|---|---|---|---|
| AI 可读取成功率 | CLI / MCP 能读取用户授权的 Markdown / JSON | 本地 Agent / CLI smoke | 命令、输出、文档 id |
| 转换后结构保留 | 标题、表格、代码块可被 AI 引用 | 样例对照 | 输入、输出、评分 |
| AI 结果回流 | 生成 Markdown / JSON 可回到手机和电脑 | CLI push / 云同步 | 结果文件、版本记录 |
| 敏感字段提醒 | token/key/secret 等字段上传前提醒 | 规则样例 | 截图 / 日志 |
