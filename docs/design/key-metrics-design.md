# 墨览关键指标

版本：v2

日期：2026-07-15

依据：`PRD.md §15`

## 1. 手机阅读

| 指标 | 目标 | 测量方式 |
|---|---:|---|
| 微信/QQ中找到墨览 | 最多滑动1-2次 | Android和iOS真机录屏 |
| 外部文件到首屏正文 | 5秒内 | 从点击“用墨览打开”开始计时 |
| 打开到完成复制 | 10秒内 | 真机完成全文、代码块或JSON字段复制 |
| 1MB以上Markdown | 不白屏、不明显卡死 | 中低端Android与iPhone手动滚动 |
| 5MB以上JSON | 不一次性展开卡死 | 展开、搜索和复制真机验证 |
| 离线阅读 | 核心操作可用 | 飞行模式打开已保存文件 |
| 异常文件 | 有明确错误 | 空文件、非法JSON、错误编码、权限失效 |

每项证据必须记录设备、系统、来源App、样例文件、步骤、耗时和截图或录屏。

## 2. 本地收集

| 指标 | 目标 |
|---|---|
| 临时打开隔离 | 未点击收集的文件不进入跨端同步 |
| 收集成功率 | 用户点击收集后原文件和元数据可靠落盘 |
| 重复收集 | 同内容不产生不可解释的重复文件 |
| 版本安全 | 编辑和导入新版本不静默覆盖旧版本 |
| 格式兜底 | 未注册但可解码的文本能使用纯文本阅读器 |

## 3. 跨端同步

| 指标 | 目标 | 测量方式 |
|---|---:|---|
| 同步成功率 | 稳定后达到99% | 客户端和服务端结构化事件 |
| 主动授权 | 100%内容上传可追溯到用户动作 | UI验收和同步事件 |
| 断网恢复 | 离线一周后能够继续同步 | 双设备模拟和真机 |
| 冲突保留 | 100%保留双方版本 | 双端基于同一旧版本编辑 |
| 删除完成度 | 删除后授权入口无法再读 | 手机、电脑、CLI、MCP联合验收 |
| 跨端一致性 | 文件ID、版本和状态一致 | 手机与电脑对照 |

## 4. 电脑与 AI

| 指标 | 目标 |
|---|---|
| 手机文件到电脑 | 用户收集后可靠进入指定电脑收件箱 |
| Office转换 | docx/pdf/pptx/xlsx/csv有真实样例和错误样例 |
| CLI契约 | 保留`ok/results/outputPath/errorCode/error` |
| AI读取授权 | 未授权文件无法读取，授权文件可稳定读取 |
| 来源追溯 | AI结果记录原文件、原版本和生成入口 |
| 结果回流 | 电脑生成结果可回到Android和iOS |

## 5. 发布质量

| 平台 | 必测内容 |
|---|---|
| Android | 签名、目标API、国产机兼容、文件入口、后台同步、包体、冷启动 |
| iOS | Share Extension、App Groups、后台传输、内存、TestFlight和审核流程 |
| Windows | 安装、MSIX或签名、文件关联、Pandoc、自动更新 |
| macOS | 签名、公证、文件关联、外部二进制签名、自动更新 |
