# 墨览权限与隐私原则

版本：v2

日期：2026-07-15

依据：`PRD.md §10`

## 1. 总原则

| 原则 | 规则 |
|---|---|
| 默认本地 | 打开、阅读、编辑、复制、分享和临时文件处理优先在本机完成 |
| 打开不等于上传 | 从微信、QQ或文件管理器打开的文件默认只在当前设备使用 |
| 主动收集 | 用户明确点击“收集到墨览”后才进入文件库 |
| 分层授权 | 收集、同步文件内容、允许 AI 读取是三个不同动作 |
| 最小权限 | 只在用户触发文件选择、分享或平台扩展时请求必要权限 |
| 内容与元数据分离 | 文件正文进入对象存储，数据库只保存元数据和引用 |
| 可撤回 | 用户能删除文件、版本、结果、设备和账号数据 |
| 冲突保留 | 多端冲突保留双方版本，不静默覆盖 |
| 不窥探输入 | 不读取其他 App 输入框，不默认监听或上传剪贴板 |

## 2. 平台权限

| 能力 | 平台能力 | 触发时机 | 必须说明 |
|---|---|---|---|
| Android 打开文件 | Intent / Storage Access Framework | 用户从外部应用打开或主动选文件 | 只读取用户选择的文件 |
| Android 后台同步 | WorkManager / 网络 | 用户开启同步且存在已授权任务 | 可延迟、可重试、可关闭 |
| Android 悬浮快贴 | `SYSTEM_ALERT_WINDOW` | 用户主动开启 | 不读取其他 App 输入内容，可随时关闭 |
| iOS 打开文件 | UTType / Document Picker / Open In | 用户从外部应用打开或主动选文件 | 只处理用户交给墨览的文件 |
| iOS 分享扩展 | Share Extension + App Groups | 用户在系统分享面板选择墨览 | 文件进入共享容器后由主应用处理 |
| iOS 后台同步 | Background URLSession / 系统任务 | 用户开启同步且系统允许 | 完成时间由系统调度，不能承诺常驻后台 |
| 剪贴板导入 | 平台剪贴板读取 | 用户明确点击导入 | 只读取当次内容，不后台监听 |
| 复制 | 平台剪贴板写入 | 用户点击复制 | 不上传复制内容 |
| 系统分享 | Share Sheet | 用户点击分享 | 目标应用由用户在系统面板选择 |
| AI 读取 | CLI / MCP / 本地或云端 API | 用户授权具体文件或集合 | 明确 AI 能看到哪些内容 |

## 3. 数据可见性

| 状态 | 设备本地 | 云端 | AI |
|---|---|---|---|
| 临时打开 | 可读 | 不可见 | 不可见 |
| 已收集、仅本地 | 文件库可见 | 不可见 | 不可见 |
| 已同步元数据 | 文件库可见 | 标题、类型、状态等可见 | 默认不可读正文 |
| 已同步内容 | 文件库可见 | 原文件或派生文件可见 | 仍需单独授权 |
| 已授权 AI | 文件库可见 | 按同步设置保存 | CLI/MCP可读授权范围 |

客户端必须让用户能够区分这些状态，不能只显示一个含糊的“已同步”。

## 4. 敏感内容提醒

本地规则可识别 `api_key`、`token`、`secret`、`password`、私钥、身份证号、手机号、邮箱和内网地址等风险模式。

规则：

- 不阻挡本地阅读；
- 在上传、分享或交给 AI 前提醒；
- 提供继续、仅本地保存、返回检查；
- 不把命中的原值写入日志；
- 规则命中只是风险提示，不宣称完成安全审计。

## 5. 删除与撤回

| 动作 | 结果 |
|---|---|
| 删除本地记录 | 删除墨览索引和阅读位置，不默认删除外部原文件 |
| 删除本地副本 | 删除墨览保存的副本，不影响其他设备和云端，除非用户另选 |
| 删除云端内容 | 删除对象引用并进入对象存储清理流程 |
| 撤回 AI 权限 | 后续读取立即拒绝；已生成结果按用户选择保留或删除 |
| 撤销设备 | 该设备会话失效，不能继续同步或读取 |
| 注销账号 | 删除账号、设备、同步数据、文件对象和任务记录，并提供处理进度 |

删除操作必须明确范围：当前设备、所有设备、云端内容或账号全部数据。

## 6. 日志

允许记录：requestId、内部用户/设备 ID、文件类型和大小、状态、错误码、耗时。

禁止记录：文件正文、提示词正文、剪贴板正文、token/secret/password 原值，以及未经授权的本地完整路径。

## 7. 验收

- 临时打开不会触发上传；
- 文件内容同步和 AI 读取分别授权；
- 权限请求发生在用户动作之后；
- 所有同步和 AI 状态可见、可撤回；
- 删除后对应 CLI、MCP 和 API 无法继续读取；
- 隐私政策与真实数据流一致。
