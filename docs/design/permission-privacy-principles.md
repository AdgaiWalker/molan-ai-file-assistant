# 墨览权限与隐私设计原则

版本：v1  
日期：2026-07-04  
对应任务：D0.5  
依据：`PRD.md §五`、`PRD.md §十一`、`TODO.md §19.1`、`docs/ai-readable-cloud-workflow.md`

## 1. 总原则

墨览的隐私边界不是设置项，而是产品架构的一部分。

| 原则 | 规则 |
|---|---|
| 默认本地 | V1 的打开、阅读、编辑、复制、转换、分享、最近文档、提示词全部本地完成 |
| 主动上传 | 文件内容只有在用户点击“保存到云端”“转给 AI 处理”“同步此文件”后才上传 |
| 最小权限 | 只在用户触发文件选择、分享、悬浮窗、键盘扩展时请求对应权限 |
| 内容和元数据分离 | 云端默认先同步提示词和记录；文件内容单独确认后上传 |
| 可撤回 | 用户必须能删除云端文件、版本、提示词和设备记录 |
| 冲突保留 | 多端冲突不覆盖旧版本，保留两个版本等待用户处理 |
| 不窥探输入 | 不读取其他 App 输入框，不默认监听剪贴板，不默认上传剪贴板 |

## 2. 权限清单

| 能力 | 权限 / 系统能力 | 触发时机 | 必须说明 | V1 / 后续 |
|---|---|---|---|---|
| 打开外部文件 | Android intent / iOS document types | 用户从微信 / QQ / 文件管理器选择墨览 | 墨览只读取用户选择的文件 | V1 |
| 选择本地文件 | DocumentPicker | 用户点击打开文件 | 不扫描全盘 | V1 |
| 读取缓存文件 | FileSystem / 沙盒缓存 | 用户打开或转换当前文件 | 仅为阅读、转换、分享临时使用 | V1 |
| 剪贴板导入提示词 | Clipboard read | 用户点击从剪贴板导入 | 只读取当次剪贴板，不后台监听 | V1 |
| 复制内容 | Clipboard write | 用户点击复制 | 写入剪贴板，不上传内容 | V1 |
| 系统分享 | Share sheet | 用户点击分享 | 由系统分享面板选择目标 | V1 |
| Android 悬浮快贴 | SYSTEM_ALERT_WINDOW | 用户主动开启悬浮快贴 | 不读取其他 App 输入框，可随时关闭 | V2 |
| iOS 键盘扩展 | Keyboard extension | 用户主动添加键盘 | 键盘只展示用户保存的提示词 | V2 |
| 云同步 | 网络请求 / 账号 | 用户登录并开启同步 | 默认只同步记录，文件内容需单独确认 | V2 |
| AI 处理 | 云端 AI / 本地 Agent | 用户点击转给 AI 处理 | 明确哪些文件会被 AI 读取 | V2 |

## 3. 本地数据边界

| 数据 | V1 存储 | 默认是否上传 | 删除规则 |
|---|---|---|---|
| 最近文档元数据 | 本地存储 | 否 | 清空最近文档时删除 |
| 阅读位置 | 本地存储 | 否 | 删除对应最近文档时删除 |
| 草稿 | 本地存储 / 缓存 | 否 | 用户丢弃草稿或清缓存时删除 |
| 提示词 | 本地存储 | 否 | 用户删除提示词时删除 |
| 复制记录 | 本地存储 | 否 | 清空最近复制时删除 |
| 转换临时文件 | 沙盒缓存 / 用户选择目录 | 否 | 转换后可清理临时文件 |
| 文件内容 | 原位置或缓存副本 | 否 | 删除缓存只删墨览副本，不删原文件 |

## 4. 云端可见性

| 数据 | V2 默认策略 | 上传前确认 | 云端可见对象 |
|---|---|---|---|
| 账号与设备 | 登录后同步 | 登录即确认 | 设备名、系统、最后同步时间 |
| 提示词库 | 可开启同步 | 开启提示词同步时确认 | 标题、内容、标签、复制统计 |
| 最近文档记录 | 可开启同步 | 开启文档记录同步时确认 | 标题、类型、来源、状态、阅读位置 |
| 文件内容 | 默认不上传 | 每个文件单独确认 | file_object、document_version |
| AI 处理任务 | 默认不开启 | 每次转给 AI 处理时确认 | 输入文件、任务类型、输出结果 |
| 删除记录 | 同步删除标记 | 删除时二次确认 | deletedAt、删除事件 |

云端 UI 必须表达三种状态：

- **仅本地**：文件内容和记录都只在当前设备。
- **已同步记录**：云端有元数据，没有文件内容。
- **已上传文件**：云端有用户主动上传的文件对象或版本。

## 5. 敏感字段提醒

本地规则先识别高风险字段，不阻断阅读，只在上传、分享、转给 AI 前提醒。

| 类别 | 关键词 / 模式 | 动作 |
|---|---|---|
| 密钥 | `api_key`、`apikey`、`secret`、`token`、`access_token`、`private_key` | 上传 / 分享前提示 |
| 账号 | `password`、`pwd`、`credential`、`cookie`、`session` | 上传 / 分享前提示 |
| 身份 | 手机号、邮箱、身份证样式字段 | 上传 / 分享前提示 |
| 内网 | `localhost`、内网 IP、私有域名 | 转给 AI 前提示 |

提醒文案原则：

- 说明发现了可能敏感字段。
- 提供“继续”“仅本地保存”“返回检查”。
- 不把敏感值写入日志。

## 6. 删除与撤回

| 场景 | 规则 |
|---|---|
| 删除本地最近文档 | 删除墨览记录和阅读位置，不删除原文件 |
| 删除本地提示词 | 删除本地提示词、标签、复制统计 |
| 删除云端记录 | 标记 deletedAt，同步到其他设备后隐藏 |
| 删除云端文件内容 | 删除 file_object 引用，后台清理对象存储 |
| 撤回 AI 处理授权 | 未开始任务取消；已完成任务可删除结果和输入引用 |
| 账号注销 | 删除账号、设备、提示词、文档记录、文件对象、任务记录 |

## 7. 日志规则

允许记录：

- requestId / taskId
- 用户 id / 设备 id 的不可逆或内部标识
- 文件类型、大小、状态、错误码
- 转换耗时、同步结果

禁止记录：

- 文件正文
- 提示词正文
- 剪贴板正文
- token / secret / password 原值
- 未经用户确认上传的原始文件路径和内容
