# D3.5 文件上传边界设计

## 1. 一句话裁定

墨览默认不上传文件内容。只有用户明确触发“保存到云端”“允许 AI 读取”“上传转换结果”这类动作，并在确认页看见范围后，文件内容才可以离开本机。

## 2. 上传层级

| 层级 | 含义 | 默认 |
|---|---|---|
| 本地记录 | 最近文件、阅读位置、状态、标签 | 开启 |
| 云端元数据 | 标题、类型、大小、hash、状态、设备来源 | 用户登录并开启云同步后可开启 |
| 文件内容 | Markdown / JSON / 转换结果对象 | 关闭，需要逐项确认 |
| AI 可读 | CLI/API 可读取文件内容给 AI | 关闭，需要单独确认 |

文件内容上传和 AI 可读是两层授权：上传到云端不等于允许 AI 读取。

## 3. 允许上传的入口

| 入口 | 可上传内容 | 必须确认 |
|---|---|---|
| AI 阅读卡片“保存到云端” | 当前 Markdown / JSON 或转换结果 | 是 |
| 最近文件“设为有用资源” | 元数据，文件内容可选 | 是 |
| 转换成功后“上传结果” | 转换后的 Markdown / PDF / Word | 是 |
| CLI `molan push` | 指定本地文件内容 | 命令行明确传入即视为主动动作 |
| 桌面 GUI 上传转换结果 | 用户选择的输出文件 | 是 |

禁止行为：
- 后台扫描并上传最近文件。
- 登录后自动上传历史文件。
- 复制到剪贴板后自动上传内容。
- 读取微信/QQ 来源文件后自动上传。
- 因收藏、加标签、加入集合而自动上传内容。

## 4. 上传确认页

确认页必须展示：

| 字段 | 说明 |
|---|---|
| 文件名 | 可编辑标题 |
| 类型 | Markdown / JSON / converted / office_source |
| 大小 | 超过阈值时高亮 |
| 来源 | 微信、QQ、文件管理器、桌面、CLI |
| 上传范围 | 仅元数据 / 上传文件内容 / 允许 AI 读取 |
| 敏感字段提醒 | 命中 token、secret、key、password 等关键词 |
| 删除说明 | 可在云端删除并撤回 AI 读取 |

默认选项：
- 仅保存元数据。
- 不上传文件内容。
- 不允许 AI 读取。

## 5. 敏感字段提醒

本地规则先行，不依赖云端：

```ts
const sensitiveKeyPatterns = [
  'token',
  'secret',
  'password',
  'passwd',
  'api_key',
  'apikey',
  'access_key',
  'private_key',
  'authorization',
  'cookie'
];
```

命中规则：
- JSON key 命中时展示字段路径，例如 `$.auth.token`。
- Markdown 文本命中时展示行号或附近标题，不展示完整敏感值。
- 命中后仍允许用户上传，但必须二次确认。
- 敏感扫描结果只留本地，不作为云端搜索字段。

## 6. 文件类型边界

| 类型 | V2 默认策略 |
|---|---|
| Markdown | 可上传内容，可允许 AI 读取 |
| JSON | 可上传内容，可允许 AI 读取，敏感字段扫描必做 |
| PDF | 可上传转换结果；AI 读取优先读转换后的 Markdown |
| Word / PPT / Excel | 不默认上传原件；优先上传转换后的 Markdown |
| 图片 | V2 不作为主流程上传 |
| 未知二进制 | 不上传，只保存元数据 |

手机端不引入 pandoc；Office 重转换仍交给桌面 CLI/GUI。

## 7. 删除与撤回

用户必须能撤回三件事：
1. 取消 AI 可读权限。
2. 删除云端文件对象。
3. 删除云端元数据记录。

删除效果：
- `pull` 不再列出正常可读项，或只列出 tombstone 用于同步删除。
- `read` 返回不可读或不存在错误。
- 已撤回 AI 可读权限的文件，即使内容对象仍在云端，也不能被 `read` 返回。
- 服务端物理删除对象后，文件 hash 和大小等最小审计字段可按隐私策略保留或脱敏。

## 8. CLI 与 GUI 边界

CLI：
- `molan push <file> --json` 是主动上传动作。
- 未来真实云端接入时，新增 `--metadata-only`、`--allow-ai-read` 只能向后扩展。
- JSON 输出继续保留 `ok/results/outputPath/errorCode/error`。

桌面 GUI：
- 上传转换结果前显示确认弹窗。
- 批量上传时每个文件都显示敏感命中和上传范围。
- 用户可选择“本批次仅保存元数据”。

## 9. 验收口径

- 登录、收藏、加标签、加入集合都不会自动上传文件内容。
- 上传前用户能清楚选择“仅元数据 / 上传内容 / 允许 AI 读取”。
- JSON/Markdown 敏感字段命中会提示，且不泄露完整敏感值。
- 撤销 AI 可读后，CLI `read` 不再返回内容。
- 删除云端文件对象后，其他设备同步后不再显示为可读。
