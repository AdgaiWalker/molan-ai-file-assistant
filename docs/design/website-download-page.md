# 墨览官网与下载页要求

版本：v2

日期：2026-07-15

## 1. 页面目标

官网帮助用户：

1. 理解“手机阅读与收集，电脑交给AI”的产品流程；
2. 获取Android、iOS、Windows、macOS和CLI的正确版本；
3. 学会从微信、QQ、浏览器和文件管理器打开文件；
4. 理解文件何时保存在本地、何时同步、何时允许AI读取；
5. 找到更新记录、FAQ和反馈入口。

## 2. 首屏

```text
墨览
手机上读文件、收集文件，电脑上交给AI使用

[Android] [App Store] [Windows] [macOS] [CLI]
```

真实下载或商店链接未准备好时显示“准备中”，不能保留空链接或假下载按钮。

## 3. 下载信息

| 平台 | 必须展示 |
|---|---|
| Android | 商店入口或APK、版本、大小、SHA256、系统要求、签名来源 |
| iOS/iPadOS | App Store或TestFlight入口、系统要求 |
| Windows | Store或安装程序、架构、大小、SHA256、是否内置Pandoc |
| macOS | 芯片架构、签名/公证说明、大小、SHA256 |
| CLI | 版本、Node要求、压缩包或安装方式、示例命令 |

## 4. 使用教程

必须使用真机截图或录屏覆盖：

- Android微信、QQ、浏览器、文件管理器打开文件；
- iOS微信、QQ、Safari、“文件”App和分享扩展；
- 临时打开与“收集到墨览”的区别；
- 手机文件同步到电脑；
- 电脑通过CLI或MCP交给AI；
- AI结果回到手机。

## 5. 隐私说明

页面显著位置说明：

- 不登录也能阅读本地文件；
- 临时打开不会自动上传；
- 收集、同步内容、允许AI读取分别授权；
- 用户可以撤回设备、删除云端内容和注销账号；
- 日志不记录文件正文；
- 完整隐私政策必须与实际数据流一致。

## 6. 版本记录和FAQ

每个版本记录对应真实发布产物和校验文件。

FAQ至少覆盖：

- 为什么微信或QQ里找不到墨览；
- 为什么文件打不开或显示乱码；
- 文件是否会上传；
- 手机文件为什么还没到电脑；
- AI为什么没有权限读取；
- Windows安全提示和macOS公证提示；
- 如何删除同步文件和注销账号。
