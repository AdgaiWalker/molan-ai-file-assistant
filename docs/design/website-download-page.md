# D5.4 官网下载页设计

## 1. 页面目标

官网下载页服务国内用户完成四件事：
1. 找到适合自己的下载包。
2. 学会从微信/QQ 打开 Markdown / JSON。
3. 理解“默认本地、不默认上传文件”。
4. 查看版本记录和反馈问题。

## 2. 首屏结构

首屏必须直接显示产品名和下载：

```text
墨览 molan
打开、阅读、复制、转换 Markdown / JSON / Office 给 AI 使用

[下载 Android APK] [下载 Windows 桌面端] [下载 CLI]
版本：v1.0.0
校验：checksums.txt
```

不做营销式长 hero；用户第一屏要能下载。

## 3. 下载区

| 下载项 | 展示字段 |
|---|---|
| Android APK | 版本、大小、SHA256、适用系统、安装说明 |
| Windows installer | 版本、大小、SHA256、是否含 pandoc |
| CLI zip | 版本、大小、SHA256、Node.js 要求、示例命令 |
| AAB | 不面向普通用户下载，仅说明商店提交材料 |

下载链接缺失时显示“准备中”或“需发布后补充”，不能放空链接。

## 4. 微信/QQ 打开教程

教程分成两页或两个折叠块：

### 微信打开
1. 在聊天里点开 `.md` 或 `.json`。
2. 选择“用其他应用打开”。
3. 在列表中找到墨览。
4. 5 秒内看到内容。

### QQ 打开
1. 打开 QQ 文件。
2. 选择更多/其他应用。
3. 选择墨览。
4. 进入阅读页或 JSON 树。

每个教程应配真机截图；没有截图时标记“待补截图”，不能用占位假图冒充。

## 5. 隐私说明

必须在下载页可见位置说明：
- 文件默认保存在本机。
- 不登录也能阅读、复制、编辑、转换、分享。
- 云同步默认关闭。
- 文件内容不默认上传。
- AI 读取需要用户授权。
- 删除云端资料后，CLI/API 不能继续读取。

下载页链接到完整隐私政策页面；V1 可先用 Markdown 页面。

## 6. 版本记录

版本记录展示：

```md
## v1.0.0
- 手机端 Markdown / JSON 阅读。
- 提示词快贴与复制。
- 当前文件转换与分享。
- CLI Office/PDF/PPT/Excel/CSV 转 Markdown。
- 已知限制：iOS/商店/真实云端待后续版本。
```

每个版本记录必须对应 release notes 和 checksum。

## 7. FAQ

V1 必备问题：
- 为什么微信里找不到墨览？
- 为什么 `.json` 打不开？
- 为什么转换 PDF/Word 失败？
- 文件会不会上传？
- CLI 怎么给 Codex/Claude Code/Cursor 用？
- Windows 安装时安全提示怎么办？

## 8. 反馈入口

反馈入口：
- GitHub Issues。
- 邮箱或表单。
- 截图/录屏上传说明。

反馈模板：

```text
设备：
系统：
App 版本：
来源 App：
文件类型：
操作步骤：
预期结果：
实际结果：
截图/录屏：
```

## 9. 验收口径

- 用户第一屏能看到 Android、Windows、CLI 下载入口。
- 每个下载项展示版本、大小、SHA256 或准备中状态。
- 微信/QQ 教程可按步骤执行。
- 隐私原则在下载页可见。
- 版本记录、FAQ、反馈入口完整。
- 未发布产物不显示假链接。
