# D1.15 App 外快贴平台方案

## 1. 定位

App 外快贴是提示词库的系统级延伸，目标是让用户在豆包、Kimi、元宝、通义、DeepSeek、ChatGPT、浏览器等 AI 输入场景里，快速找到并复制已保存的提示词。

它不是输入法监控器，不是剪贴板监听器，不是广告浮窗，也不是全局 AI 聊天入口。

V1 先完成 App 内提示词库；App 外快贴进入 V1.5 / V2 增强。

## 2. 统一原则

- 默认关闭。
- 必须用户主动开启和授权。
- 必须有明显关闭入口。
- 不读取其他 App 输入框内容。
- 不后台监听剪贴板。
- 不默认上传剪贴板或提示词内容。
- 复制动作由用户点击触发，只写入系统剪贴板。
- 权限说明用短文案说清楚用途、风险和关闭方式。

## 3. Android：悬浮快贴

### 3.1 适用场景

Android 允许系统悬浮窗，适合提供一个可移动的墨览小按钮：

```text
用户打开 AI App
  -> 点击墨览悬浮小窗
  -> 出现迷你提示词面板
  -> 搜索 / 选择提示词
  -> 点击复制
  -> 回到 AI 输入框粘贴
```

### 3.2 权限

| 权限 | 触发时机 | 说明 |
|---|---|---|
| 悬浮窗权限 | 用户在设置中开启“Android 悬浮快贴” | 用于在其他 App 上方展示提示词入口 |
| 剪贴板写入 | 用户点击复制提示词 | 只写入用户选中的提示词 |
| 剪贴板读取 | 不用于悬浮快贴默认流程 | 仅 App 内“从剪贴板导入”按钮触发 |
| 网络 | 不依赖 | 云同步开启后只同步提示词库，不读取当前输入 |

### 3.3 UI 形态

| 状态 | 展示 |
|---|---|
| 关闭 | 设置页显示“未开启” |
| 悬浮球 | 32-44px，墨览图标或文件点图标，贴边吸附 |
| 迷你面板 | 搜索框 + 最近复制 5 条 + 收藏/常用 |
| 详情面板 | 提示词标题、内容预览、变量占位、复制按钮 |
| 复制成功 | 面板短反馈，可自动收起 |
| 权限失效 | 提示重新授权，不闪退 |

视觉遵循 `docs/design/mobile-visual-spec.md`：白底/深色 surface、蓝色主操作、小圆角、少装饰。

### 3.4 交互规则

- 悬浮球不得遮挡键盘输入框和发送按钮；初始位置贴屏幕右侧中下部。
- 用户可拖动，位置本地记忆。
- 点击外部可收起面板。
- 长按悬浮球进入关闭/设置。
- 复制后默认不自动粘贴，避免越权操作。
- 可选“复制后自动收起”，默认开启。

### 3.5 关闭入口

关闭入口必须至少有三处：

- 悬浮球长按菜单：关闭本次 / 永久关闭。
- 迷你面板右上角关闭。
- 设置页：关闭 Android 悬浮快贴并跳转系统权限页。

## 4. iOS：键盘扩展 / 分享扩展

iOS 不按 Android 悬浮窗设计。优先级：

1. App 内提示词库 + 系统复制粘贴，覆盖 V1。
2. 分享扩展：从其他 App 分享文本或文件到墨览，加入提示词或打开阅读。
3. 键盘扩展：在输入场景展示用户保存的提示词，点击复制/插入。

### 4.1 键盘扩展

| 项 | 方案 |
|---|---|
| 入口 | 用户在系统设置中添加墨览键盘 |
| 数据 | 只读取用户主动保存的提示词库 |
| 搜索 | 本地搜索标题、标签、正文 |
| 输出 | 点击提示词后插入或复制 |
| 网络 | 默认不联网；云同步由主 App 完成 |
| 隐私 | 明确说明不读取用户输入内容，不上传输入框内容 |

关键限制：

- 不要求“完全访问”作为默认条件。
- 若系统限制导致无法共享完整提示词库，需要在主 App 里生成键盘扩展可读的本地共享数据。
- 键盘扩展 UI 更窄，只展示搜索、最近、收藏、复制/插入。

### 4.2 分享扩展

分享扩展用于“把外部内容交给墨览”，不是用于覆盖 AI 输入框：

| 来源 | 目标 |
|---|---|
| 浏览器网页文本 | 存为提示词片段或 Markdown |
| 微信/QQ 文件 | 打开阅读或加入最近收件箱 |
| AI App 输出 | 保存为提示词、待办或 AI 可读资源 |
| 其他编辑器文本 | 保存到提示词库或导出 Markdown |

分享扩展不自动上传内容；保存前展示内容预览和目标。

## 5. 权限说明文案

### Android 悬浮窗

```text
开启后，墨览会在其他 App 上方显示一个可关闭的小按钮，方便你搜索并复制已保存的提示词。
墨览不会读取其他 App 输入框内容，不会自动读取或上传剪贴板。
```

### iOS 键盘扩展

```text
墨览键盘只展示你保存的提示词，方便在输入时复制或插入。
墨览不会上传你的输入内容，也不会把键盘输入自动保存到提示词库。
```

### 分享扩展

```text
你分享给墨览的内容会先在本机预览。只有你主动保存、分享或转给 AI 处理时，才进入对应流程。
```

## 6. 隐私边界

| 数据 | 默认行为 |
|---|---|
| 其他 App 输入框 | 不读取 |
| 剪贴板内容 | 不后台读取，不默认上传 |
| 已保存提示词 | 本地展示，云同步需用户开启 |
| 当前 AI 对话内容 | 不读取 |
| 文件内容 | 不默认上传 |
| 悬浮窗位置 | 本地保存 |
| 最近复制 | 本地保存，云同步需用户开启 |

敏感字段策略：

- 如果提示词内容包含 token/secret/key，复制前不阻断，但可在详情中显示敏感提醒。
- 云同步开启后，带敏感标记的提示词默认不同步，或需要用户二次确认。

## 7. 与 App 内提示词库的数据关系

App 外快贴只消费同一套提示词库：

- App 内保存的提示词。
- 从 Markdown / JSON 导入的提示词。
- 从 AI 阅读卡片导入的提示词候选。
- 后续云同步下发的提示词。

不创建第二套提示词数据模型；标签、收藏、最近复制、变量模板都沿用 `PromptItem` 的后续扩展字段。

## 8. 实施阶段

| 阶段 | 范围 | 验收 |
|---|---|---|
| V1 | App 内提示词库、剪贴板导入、当前文件导入 | 打开文档到复制提示词 10 秒内 |
| V1.5 | Android 悬浮快贴原型、设置页开关、权限说明 | 用户可开启、复制、关闭 |
| V2 | iOS 分享扩展 / 键盘扩展方案落地、云同步提示词 | 不读取输入框，不默认上传 |
| V3 | 团队提示词策略、企业权限 | 审计、权限、策略可控 |

## 9. 验收口径

- Android 悬浮快贴默认关闭，开启前有用途和隐私说明。
- Android 悬浮窗可拖动、可收起、可关闭，不遮挡输入框和发送按钮。
- iOS 不承诺悬浮窗，使用键盘扩展 / 分享扩展 / App 内复制粘贴组合。
- 剪贴板只在用户点击导入或复制时访问。
- App 外快贴与 App 内提示词库共享数据模型，不另起一套。
