# 墨览端到端使用场景地图

版本：v1  
日期：2026-07-04  
对应任务：D0.1  
依据：`PRD.md`、`TODO.md`、`docs/full-plan.md`、`docs/ai-readable-cloud-workflow.md`

## 1. 场景地图总览

墨览的端到端链路不是单个阅读器页面，而是把散落文件送入“人能读、AI 能读、能回流”的工作流。

```text
外部来源
  -> 手机快开与筛选
  -> 阅读 / 复制 / 编辑 / 转换 / 分享
  -> 本地记录与提示词库
  -> 用户主动保存到云端
  -> 电脑 CLI / GUI / Agent 读取
  -> AI 生产结果
  -> 回流到手机 / 电脑继续使用
```

V1 先闭合本地链路：快开、阅读、复制、编辑、当前文件转换、分享、最近文档、提示词。V1.5 扩展批量转换和提示词管理。V2 以后才把用户主动选择的资料进入云端和 AI 读取闭环。

## 2. 入口来源

| 来源 | 用户动作 | 墨览接收内容 | 第一屏 | 成功标准 | 失败兜底 |
|---|---|---|---|---|---|
| 微信文件 | 在“其他应用”中选择墨览 | `.md` / `.markdown` / `.json` | 阅读页 | 1-2 次滑动内找到墨览，5 秒内看到内容 | 显示读取失败原因，允许重新选择文件或保存到本地再打开 |
| QQ 文件 | 在“其他应用”中选择墨览 | `.md` / `.markdown` / `.json` | 阅读页 | 1-2 次滑动内找到墨览，5 秒内看到内容 | 同微信；记录来源为 QQ 或 unknown |
| 文件管理器 | 点开本地文件 | Markdown / JSON / 文本 | 阅读页 | `content://` 和本地路径都能读取 | 提示权限或 URI 读取失败，不扫描全盘 |
| 本地电脑创建 | 通过聊天、网盘、数据线传到手机 | Markdown / JSON / 转换结果 | 阅读页或收件箱 | 保留来源、类型、最近打开 | 无法识别类型时按文本打开 |
| GitHub 下载 | 下载 README / PRD / 配置 | Markdown / JSON / 代码文本 | 阅读页 | README/PRD 可读，代码块可复制 | 大文件提示性能风险 |
| AI App / 浏览器下载 | 下载提示词、Agent 配置、结构化输出 | Markdown / JSON | 阅读页或 JSON 树 | 能复制提示词、字段值、JSONPath | JSON 非法时进入原文错误态 |
| 电脑 Office 转换 | CLI / GUI 转出 Markdown | Markdown / 资源目录 | 电脑输出目录或云端收件箱 | AI 可读 JSON 日志 + Markdown 文件 | 转换失败有错误码和输出路径 |
| AI 生产结果 | AI 生成 Markdown / JSON | 结果文档 | 云端收件箱 / 最近文档 | 手机和电脑均可继续阅读、编辑、分享 | 冲突时保留两个版本 |

## 3. 手机 V1 本地闭环

```text
微信 / QQ / 文件管理器收到文件
  -> 墨览打开
  -> 直接进入 Markdown 阅读页或 JSON 阅读页
  -> 用户复制全文、代码块、JSON 字段或提示词
  -> 用户可轻量编辑并保存副本
  -> 用户选择分享原文件、纯文本、PDF 或 Word
  -> 系统分享面板发送到微信 / QQ / 其他应用
  -> 最近文档记录来源、类型、状态、阅读位置
```

关键约束：

- 打开文件后先阅读，不先要求导入、登录、识别或上传。
- 复制是高频主动作，转换是办公分享动作。
- 最近文档记录只保存必要元数据，文件内容默认本地。
- 所有核心动作离线可用。

## 4. 提示词快贴闭环

```text
用户从文件或剪贴板得到提示词
  -> 保存到提示词库
  -> 搜索 / 收藏 / 最近复制
  -> 一键复制或组合复制
  -> 切到 AI App 粘贴使用
  -> 复制事件回写最近复制
```

V1 只要求 App 内快贴成立。Android 悬浮快贴和 iOS 键盘 / 分享扩展属于后续增强，必须用户主动授权，且不读取其他 App 输入框。

## 5. 电脑 CLI 与 GUI 闭环

```text
Office / PDF / PPT / Excel / CSV
  -> molan convert
  -> 共享 converter 调用 pandoc / 外部转换器
  -> 输出 Markdown
  -> 输出结构化 JSON 日志
  -> AI / Agent 读取 Markdown 和 JSON 日志
```

电脑 GUI 是人用轻量入口：

```text
拖入文件
  -> 选择输出格式
  -> 批量转换
  -> 查看成功 / 失败列表
  -> 打开输出目录或预览 Markdown / JSON
```

电脑置顶快贴窗服务开发场景：

```text
IDE / AI Agent 工作中
  -> 呼出墨览快贴窗
  -> 搜索提示词
  -> 一键复制
  -> 回到开发窗口粘贴
```

## 6. 云端与 AI 读取闭环

云端从 V2 开始，不是 V1 的前置条件。

```text
手机端用户标记文件有用
  -> 明确点击保存到云端 / 转给 AI 处理
  -> 敏感字段提醒与上传确认
  -> 云端保存元数据与可选文件对象
  -> 电脑 CLI pull / read 拉取
  -> AI 读取并生成 Markdown / JSON
  -> molan push 或云端 API 写回
  -> 手机端收件箱同步结果
```

原则：

- 默认不上传文件内容。
- 文件对象和元数据分离。
- 冲突默认保留，不覆盖。
- CLI 优先，MCP 后置，云端 API 最后开放。

## 7. 状态流转

| 状态 | 触发动作 | 用途 |
|---|---|---|
| 未处理 | 首次从外部打开或同步进入收件箱 | 提醒用户筛选 |
| 已阅读 | 阅读页成功展示 | 证明入口成立 |
| 已复制 | 复制全文、代码块、字段、提示词 | 记录高频价值动作 |
| 已编辑 | 保存草稿或副本 | 区分原文件与用户修改 |
| 已转换 | 生成 PDF / Word / Markdown | 支撑办公分享和 AI 读取 |
| 已分享 | 调起分享或保存到本地成功 | 完成社交/办公转发 |
| 已归档 | 用户主动归档 | 收件箱降噪 |
| 已同步 | 用户主动云备份后同步成功 | 多端找回 |
| 冲突 | 多端版本同时变化 | 保留两份，等待用户处理 |
