# 手机端提示词库设计

版本：v1  
日期：2026-07-04  
对应任务：D1.6  
依据：`mobile/src/components/PromptSheet.tsx`、`mobile/src/storage/prompts.ts`、`docs/design/mobile-copy-system.md`

## 1. 定位

提示词库不是普通收藏夹，而是手机端 AI 工具的快贴面板：

```text
保存常用提示词 / 文件片段
  -> 搜索或打开最近复制
  -> 一键复制 / 组合复制
  -> 粘贴到 AI App
```

V1 先做 App 内提示词库；Android 悬浮窗、iOS 键盘扩展和云同步放到 V2。

## 2. 设计范围

实现参考：`mobile/src/components/PromptSheet.tsx`、`mobile/src/storage/prompts.ts`。

## 4. 数据模型

| 字段 | 用途 | V1 | V1.5 / V2 |
|---|---|---|---|
| `id` | 唯一标识 | 必须 | 云端同步保持稳定 |
| `title` | 展示和搜索 | 必须 | 可编辑 |
| `content` | 复制正文 | 必须 | 可用变量模板 |
| `format` | md/json/text | 必须 | 影响预览和导入规则 |
| `tags` | 标签搜索 | 字段已存在 | 标签管理 UI |
| `folderId` | 分组 | 字段已存在 | 分组管理 UI |
| `copyCount` | 高频排序 | 必须 | 同步统计 |
| `lastCopiedAt` | 最近复制 | 必须 | 跨设备恢复 |
| `createdAt` | 排序 / 同步 | 必须 | 云端增量 |

## 5. 核心流程

### 5.1 一键复制

```text
打开提示词库
  -> 搜索或查看最近复制
  -> 点击“复制”
  -> 写入剪贴板
  -> copyCount + 1
  -> lastCopiedAt = now
  -> 按钮短暂显示“已复制”
```

### 5.2 从剪贴板导入

```text
点击“从剪贴板导入”
  -> 主动读取剪贴板
  -> 剪贴板为空：toast
  -> 剪贴板有内容：打开导入对话框
  -> 用户编辑标题
  -> 导入为 PromptItem
```

隐私裁定：不后台监听剪贴板，只在用户点击导入时读取。

### 5.3 从当前文件导入

```text
阅读页打开提示词库
  -> 点击“导入当前文档”
  -> 根据内容判断 md/json/text
  -> 保存为提示词
  -> toast “已导入当前文档”
```

### 5.4 从片段导入

```text
用户在正文 / 代码块 / JSON 字段复制片段
  -> 打开提示词库
  -> 点击“导入剪贴板片段”
  -> 编辑标题
  -> 保存为提示词
```

### 5.5 复制整个分组 / 列表

V1 当前用“复制列表全部”覆盖：

```text
搜索或筛选列表
  -> 点击复制列表全部
  -> 将每条 content 用分隔线合并
  -> 写入剪贴板
```

V1.5 分组管理完成后，列表来源可以是分组、标签或搜索结果。

## 6. 收藏、标签、分组

| 能力 | V1 | V1.5 |
|---|---|---|
| 收藏 | 可先用 seed / copyCount 近似常用 | 增加 favorite 字段和收藏筛选 |
| 标签 | 数据字段存在，搜索可查 | 标签编辑、标签筛选、批量改标签 |
| 分组 | `folderId` 字段存在 | 新增 / 重命名 / 删除分组 |
| 最近复制 | 已可用 | 跨设备同步 |
| 搜索 | 已可用 | 搜索高亮、空态建议 |

## 7. 状态与空态

| 状态 | UI |
|---|---|
| 首次进入 | 若无本地数据，加载 seed prompts |
| 无提示词 | 显示“暂无提示词” |
| 搜索无结果 | 显示“没有匹配的提示词” |
| 剪贴板为空 | toast “剪贴板为空” |
| 当前文件为空 | toast “当前无可导入内容” |
| 复制成功 | 按钮“已复制” |
| 批量复制成功 | toast “已复制 N 条” |
| 导入成功 | toast “已导入” |
