# D1.13 手机端全量页面状态表

## 1. 状态原则

- 所有页面必须有空态、加载态、错误态；不能白屏。
- 离线不阻塞本地阅读、复制、编辑、提示词、最近记录和本地转换。
- 大文件与大 JSON 要先提示风险，再进入降级阅读或转换。
- 转换失败、同步冲突、权限失败必须给用户下一步动作。
- 状态文案必须短，详细原因放在二级说明或错误详情。

## 2. 全局状态

| 状态 | 触发 | 展示 | 动作 |
|---|---|---|---|
| 首次进入 | 无打开文件、无最近记录 | 首页 + 打开文件按钮 + 微信/QQ 打开指引 | 打开文件、查看指引 |
| 加载中 | 外部 URI / 文件选择器读取中 | 顶部或操作按钮 loading，禁用重复打开 | 等待、取消由系统负责 |
| 打开错误 | 文件读取失败、格式不支持 | 错误条展示友好原因 | 重新选择 |
| 无权限 | Android READ 权限或安全 URI 失败 | 提示保存到本地后从墨览打开 | 重新选择、看指引 |
| 离线 | 无网络 | 不弹全局错误，本地能力继续可用 | 云同步显示未连接 |
| 大文件风险 | 文件体积超阈值或长文本 | 提示可能卡顿 / 转换耗时 | 继续打开、取消 |
| 分享不可用 | 系统分享能力不可用 | 错误条提示当前环境不支持分享 | 复制文本、保存副本 |
| 同步冲突 | 同一文档多端状态或版本不一致 | 冲突状态徽标 | 保留两份、稍后解决 |

## 4. 页面局部状态

### 4.1 搜索

| 页面 | 无结果 |
|---|---|
| Markdown 阅读 | 显示“没有找到匹配内容”，保留搜索词 |
| JSON 阅读 | 显示“没有匹配字段或值”，保留树结构入口 |
| 提示词库 | 显示“没有匹配的提示词”，提供清空搜索 |
| 最近文档 | 显示“没有找到匹配文档”，提供清空搜索 |

### 4.2 复制

| 状态 | 展示 | 动作 |
|---|---|---|
| 无可复制内容 | 错误条或 toast | 返回阅读 |
| 复制成功 | 短反馈，不打断阅读 | 可继续复制 |
| 复制失败 | 错误条展示失败原因 | 重试、手动选择文本 |

### 4.3 JSON 校验

| 状态 | 展示 | 动作 |
|---|---|---|
| 合法 JSON | 可格式化、可保存、可分享 | 保存/副本/分享 |
| 非法 JSON | 错误条 + 禁用覆盖保存 | 继续编辑、关闭、保存原文副本后续再定 |
| 大 JSON | 折叠大数组，必要时原文预览 | 搜索降级、复制路径 |

### 4.4 云同步

| 状态 | 展示 | 动作 |
|---|---|---|
| 未启用 | 设置页显示未启用 | 不请求账号 |
| 离线等待 | 显示“待同步” | 本地继续 |
| 已同步 | 状态徽标 | 无 |
| 冲突 | 冲突徽标 + 时间 | 保留两份，选择版本 |
| 同步失败 | 错误详情 | 重试、关闭同步 |

## 5. 文案约束

- 错误文案先说结果，再说下一步，例如“无法读取来自微信的文件。请先保存到本地，或重新选择。”
- 不展示技术堆栈给普通用户；详细错误只在转换日志或调试入口展示。
- 同步、AI、上传相关文案必须明确“需要用户主动开启/点击”。
- 敏感字段提醒不能暗示已经上传或自动清理。

## 6. 验收口径

- 每个页面在空态、错误态下都有可见文案和下一步动作。
- 无权限、离线、大文件、转换失败、同步冲突均有明确归属页面。
- 打开、复制、编辑、转换、分享任一失败不会造成白屏或丢草稿。
- D1.1 / D1.2 真机验收时，截图需覆盖打开错误、加载、阅读空态或目录空态。
