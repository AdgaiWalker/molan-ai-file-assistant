# D2.7 电脑端置顶快贴窗设计

## 1. 定位

电脑端置顶快贴窗服务开发和 AI Agent 工作场景：

```text
打开 IDE / Codex / Claude Code / Cursor
  -> 呼出墨览快贴窗
  -> 搜索 review / todo / api / agent 等提示词
  -> 点击复制
  -> 回到开发窗口粘贴
```

它不是完整文档编辑器，不替代 CLI，也不读取 IDE 输入框内容。

## 2. 设计范围

实现参考：`desktop/src/components/PromptPanel.tsx`、Electron 主进程的 `createPromptWindow`。

当前缺口：

- 提示词数据仍是静态 `DEFAULT_PROMPTS`。
- 复制后没有可靠“回到上一个开发窗口”。
- 快捷命令模式未实现。
- 变量填写、组合、编辑按钮还未接真实逻辑。
- 云同步状态是静态文案。

## 3. 窗口模式

### 3.1 侧边置顶模式

默认推荐模式：

- 宽度 320-420，高度 560-720。
- 贴屏幕左侧或右侧。
- always-on-top。
- 不抢主窗口布局。
- 显示搜索、最近复制、收藏、开发常用分组。
- 右侧或下方显示提示词详情。

### 3.2 Mini 模式

用于屏幕空间紧张时：

- 只显示搜索框和最近 5 条。
- 宽度 280-360。
- 隐藏详情面板。
- 回车复制当前高亮项。
- Esc 收起或关闭。

### 3.3 快捷命令模式

类似命令面板：

```text
Ctrl/Command + Shift + M
  -> 小窗聚焦搜索
  -> 输入 review
  -> ↑/↓ 选择
  -> Enter 复制
  -> 窗口自动隐藏或失焦
```

快捷命令只做提示词搜索和复制，不做编辑。

## 4. 提示词详情

详情区显示：

- 标题。
- 正文。
- 标签。
- 变量占位：`{{文件内容}}`、`{{代码片段}}`、`{{JSON}}`。
- 复制按钮。
- 组合按钮。
- 编辑按钮。

交互：

- 单击列表项选中。
- 双击列表项直接复制。
- 点击复制按钮复制正文。
- 变量模板有未填变量时，复制前弹出轻量填写区。
- 编辑在主窗口或详情模式完成，不在 Mini 模式塞复杂表单。

## 5. 复制工作流

默认：

```text
点击复制
  -> 写入系统剪贴板
  -> 显示“已复制”
  -> 可选自动隐藏快贴窗
  -> 用户回到开发窗口粘贴
```

后续增强：

- 复制后自动隐藏。
- 记录最近复制。
- 尝试恢复上一个 focused window。

平台边界：

- Electron 可写剪贴板。
- 不读取 IDE 输入框。
- 不自动粘贴到其他应用。
- 如果恢复焦点不稳定，宁可只隐藏窗口，不做危险模拟按键。

## 6. 快捷键

| 快捷键 | 行为 |
|---|---|
| `Ctrl/Command+Shift+M` | 打开/聚焦快贴窗 |
| `Ctrl/Command+K` | 聚焦搜索 |
| `Enter` | 复制当前选中提示词 |
| `Esc` | 清空搜索；再次按关闭/隐藏 |
| `↑/↓` | 切换搜索结果 |
| `Ctrl/Command+Enter` | 组合复制或填变量后复制 |

快捷键冲突时：

- 不覆盖系统关键快捷键。
- 允许用户后续在设置里关闭全局快捷键。

## 7. 数据关系

快贴窗使用同一套提示词库：

- 手机端保存的提示词。
- 电脑端新增的提示词。
- 云端同步的提示词。
- 从 Markdown / JSON 提取的提示词。
- 从 AI 阅读卡片保存的候选。

后续数据字段：

```ts
interface DesktopPromptItem {
  id: string;
  title: string;
  content: string;
  group?: string;
  tags: string[];
  favorite?: boolean;
  copyCount: number;
  lastCopiedAt?: string;
  variables?: string[];
  source?: 'mobile' | 'desktop' | 'cloud' | 'ai-card' | 'import';
  updatedAt: string;
}
```

不为桌面快贴另建一套提示词模型。

## 8. 轻量转换入口

快贴窗可提供轻量转换入口，但不能喧宾夺主：

- 拖入 Word / PDF / PPT / Excel。
- 转 Markdown。
- 复制 Markdown 内容。
- 保存到云端。
- 给 AI 读取。

入口位置：

- 详情区底部“转换文件”。
- 快捷命令 `/convert`。

转换入口默认折叠，不影响搜索提示词。

## 9. 状态与失败

| 状态 | 展示 |
|---|---|
| 无提示词 | 显示导入/新增入口 |
| 搜索无结果 | 显示“没有匹配提示词” |
| 复制成功 | 行内“已复制” 1.2 秒 |
| 复制失败 | 错误条，不关闭窗口 |
| 云同步未启用 | 显示“本地”或“未同步” |
| 云同步失败 | 显示重试，不影响本地复制 |
| 快捷键注册失败 | 设置页显示错误，可手动打开窗口 |

## 10. 视觉规则

依据用户给的电脑端参考图：

- 小型白色浮窗，8-12 圆角。
- 主窗口贴边，不使用大型卡片嵌套。
- 搜索框顶部固定。
- 列表项紧凑，适合扫读。
- 同步状态轻量展示，不喧宾夺主。
- 工具按钮优先图标化；文字用于关键命令。

## 11. 验收口径

- 快贴窗可通过快捷键打开并保持置顶。
- 侧边模式不遮挡主开发窗口主体。
- Mini 模式只保留搜索和最近提示词。
- 搜索、选择、复制闭环 3 秒内完成。
- 提示词详情可复制、组合、编辑入口清楚。
- 复制后不读取输入框、不自动粘贴、不默认监听剪贴板。
