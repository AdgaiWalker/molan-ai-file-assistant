# 墨览全量信息架构 IA

版本：v1  
日期：2026-07-04  
对应任务：D0.6  
依据：`PRD.md §六`、`PRD.md §十`、`docs/design/end-to-end-scenario-map.md`

## 1. IA 总览

```text
外部打开入口
  -> 阅读页
     -> 复制
     -> 编辑页
     -> 分享
     -> 当前文件转换
     -> AI 阅读卡片
     -> 加入提示词库
     -> 最近文档 / 收件箱状态

主动打开 App
  -> 首页
     -> 最近文档
     -> 提示词库
     -> 打开文件
     -> 转换中心
     -> 云端收件箱
     -> 设置

电脑端
  -> CLI
  -> 桌面 GUI
  -> 置顶快贴窗
```

原则：外部文件打开时不经过首页，直接进入阅读页；首页只服务用户主动启动 App 的场景。

## 2. 手机端一级结构

| 模块 | 入口 | 主任务 | 首屏优先级 | 版本 |
|---|---|---|---|---|
| 首页 / 今天 | App 图标启动 | 回到最近文件、复制提示词、打开文件、进入转换中心 | P0 | V1 |
| 阅读页 | 外部打开、最近文档、收件箱 | 阅读 Markdown / JSON，复制，编辑，分享，转换 | P0 | V1 |
| 编辑页 | 阅读页编辑按钮 | 原文编辑、预览、JSON 校验、保存副本、分享 | P0 | V1 |
| 提示词库 / 快贴 | 首页、阅读页加入提示词 | 搜索、收藏、最近复制、一键复制、剪贴板导入 | P0/P1 | V1/V1.5 |
| 最近文档 | 首页、底部入口或 Sheet | 最近打开、最近编辑、最近复制、状态筛选 | P0 | V1 |
| 转换中心 | 首页、阅读页转格式 | 当前文件转换；V1.5 多文件队列 | P0/P1 | V1/V1.5 |
| AI 阅读卡片 | 阅读页底部卡片 | 文件类型、摘要、提示词候选、敏感字段、保存建议 | P2 | V2 |
| 云端收件箱 | 首页、设置、AI 卡片 | 云同步文件、电脑结果回流、历史找回 | P2 | V2 |
| 设置 | 首页 | 默认打开指引、云同步、隐私、缓存、导出数据 | P0/P2 | V1/V2 |

## 3. 首页 IA

| 区块 | 内容 | 动作 | 空态 |
|---|---|---|---|
| 状态条 | 本地优先 / 云同步状态 | 打开同步设置 | 显示“本地优先，可选云同步” |
| 打开文件 | 主按钮 | 调用文件选择器 | 无 |
| 最近文档 | 最近 3-5 个文件 | 打开、更多、状态菜单 | 引导从微信 / QQ 或本地打开 |
| 快捷入口 | 提示词快贴、云端收件箱、转换中心 | 进入对应模块 | 保持可见 |
| 常用提示词 | 收藏和最近复制 | 一键复制、搜索 | 引导剪贴板导入 |
| 底部动作 | 文件、加号、提示词、我的 | 切换核心模块 | V1 可保持轻导航 |

首页不做营销说明，不放复杂 tab，不加载文件正文。

## 4. 阅读页 IA

| 区块 | Markdown | JSON | 主动作 |
|---|---|---|---|
| 顶栏 | 返回、标题、来源、更多 | 返回、标题、来源、更多 | 打开操作菜单 |
| 正文 | Markdown 分块渲染 | JSON 树 | 阅读 |
| 快捷操作 | 复制、编辑、AI 可读、转换、分享 | 复制、编辑、字段操作、转换、分享 | 高频动作 |
| 搜索 / 目录 | 目录跳转、全文搜索 | key/value 搜索 | 定位内容 |
| 状态提示 | 草稿、转换中、分享结果 | JSON 错误、压缩/美化状态 | 反馈 |
| AI 阅读卡片 | 摘要、提示词候选、敏感字段 | 结构解释、prompt/config 字段 | V2 增强 |

阅读页必须支持：

- 内容先出现，操作面板可后出现。
- 代码块、表格横向滚动。
- JSON 默认按需展开，不一次性展开大树。
- 外部打开失败时显示原因和重新选择入口。

## 5. 编辑页 IA

| 区块 | Markdown 编辑 | JSON 编辑 |
|---|---|---|
| 顶栏 | 返回、标题、保存副本、分享 | 返回、标题、格式化、保存副本 |
| 模式切换 | 编辑 / 预览 | 编辑 / 树形预览 |
| 主编辑区 | 原文文本 | 原文 JSON |
| 校验状态 | Markdown 无阻断校验 | JSON 语法错误、错误行列 |
| 草稿提示 | 自动保存中 / 已保存 | 自动保存中 / 已保存 |
| 底部动作 | 保存副本、分享 | 格式化、压缩、保存副本、分享 |

非法 JSON 不覆盖原文件；保存副本优先于覆盖原文件。

## 7. 最近文档与收件箱 IA

| 视图 | 数据 | 动作 | 版本 |
|---|---|---|---|
| 最近打开 | 文件名、类型、来源、时间 | 打开、删除记录 | V1 |
| 最近编辑 | 草稿 / 副本状态 | 继续编辑、丢弃草稿 | V1 |
| 最近复制 | 文档复制状态 | 重新打开、复制 | V1 |
| 文件收件箱 | 未处理、已阅读、已复制、已转换、已分享、已归档 | 标记、归档、筛选 | V1/V1.5 |
| 云端收件箱 | 已同步记录、已上传文件、电脑结果 | 拉取、保存本地、删除云端 | V2 |

## 8. 转换中心 IA

| 区块 | V1 | V1.5 |
|---|---|---|
| 输入 | 当前文件 | 多文件添加、队列 |
| 配方 | 给别人看 PDF；给别人改 Word；给 AI Markdown | 格式推荐、批量配方 |
| 进度 | 当前转换中 | 队列进度、单项暂停 / 重试 |
| 结果 | 直接分享、保存本地 | 成功 / 失败列表、批量分享 |
| 错误 | 失败原因、重试 | 失败隔离、错误详情 |

## 9. AI 阅读卡片 IA

V2 增强，不阻断 V1 阅读。

| 区块 | 内容 | 动作 |
|---|---|---|
| 文件类型 | PRD、README、提示词、API JSON、Agent 配置、日志 | 查看依据 |
| 内容摘要 | 关键段落、待办、结论 | 复制摘要 |
| 提示词候选 | prompt / rules / system message | 保存到提示词库 |
| 敏感字段 | token/key/secret 提醒 | 返回检查、继续 |
| 保存建议 | 仅本地、保存记录、上传文件、转给 AI | 用户主动选择 |
