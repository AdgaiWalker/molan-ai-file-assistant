# D5.1 真机验证脚本

## 1. 目标

真机验收验证 V1 用户是否能从微信、QQ、文件管理器进入墨览，并在目标时间内完成阅读、复制、转换和分享。

本脚本用于每次发布前手动执行；没有连接真机时，不得把 D1.1/D1.2 的真机任务改为完成。

| 网络 | 离线 / Wi-Fi / 蜂窝 |
| 录屏/截图 | 文件路径或链接 |

## 3. 微信打开 `.md`

步骤：
1. 在微信聊天中接收 `.md` 文件。
2. 点开文件预览。
3. 选择“用其他应用打开”。
4. 在 1-2 次滑动内找到墨览。
5. 选择墨览打开。

通过标准：
- 5 秒内看到正文内容。
- 标题与文件名一致或可识别。
- 无白屏、无崩溃、无 safe-area 遮挡。
- 最近文件出现该文件，来源标记为微信或外部来源。

## 4. 微信打开 `.json`

步骤同 `.md`，样例使用至少三层嵌套 JSON。

通过标准：
- 5 秒内看到 JSON 树。
- 可展开/折叠。
- 可复制字段值。
- 可复制 JSONPath。

## 5. QQ 打开 `.md` / `.json`

步骤：
1. 在 QQ 聊天接收 `.md` 和 `.json`。
2. 从 QQ 文件页选择用墨览打开。
3. 分别验证 Markdown 阅读页和 JSON 阅读页。

通过标准：
- 墨览能出现在打开方式列表。
- 5 秒内看到内容。
- 最近文件记录来源为 QQ 或外部来源。
- 返回 QQ 后再次打开同文件不崩溃。

## 6. 文件管理器打开

步骤：
1. 将 `.md` 和 `.json` 放入 Downloads。
2. 从系统文件管理器点开。
3. 选择墨览。

通过标准：
- Android `content://` 文件可读。
- 文件名、类型、内容正确。
- 无权限错误。

## 7. 复制验收

Markdown：
- 复制全文。
- 复制代码块。
- 复制选中片段。

JSON：
- 复制字段值。
- 复制 JSONPath。
- 复制节点。

通过标准：
- 10 秒内完成至少一种复制。
- 系统剪贴板内容正确。
- UI 有成功反馈。
- 最近文件状态增加 `copied`。

## 8. 转换与分享验收

Markdown：
1. 打开 Markdown。
2. 转换为 PDF。
3. 调出系统分享面板。
4. 分享到微信或 QQ。

通过标准：
- 20 秒内完成转换并出现分享面板。
- 生成文件名可识别。
- 分享失败时有错误提示。
- 最近文件状态增加 `converted` 和 `shared`。

## 9. safe-area 验收

检查设备：
- 刘海屏。
- 挖孔屏。
- 底部手势导航。
- 横竖屏切换。

通过标准：
- 顶部按钮不被状态栏遮挡。
- 底部操作栏不被 Home Indicator 或手势区域遮挡。
- 长文滚动到底部时最后一行可见。

## 10. 启动速度

测量方法：
1. 冷启动前强制结束 App。
2. 从微信/QQ/文件管理器打开文件。
3. 录屏计时从点击墨览到正文首屏可见。

目标：
- 5 秒内看到内容。
- 失败时记录文件大小、设备型号、系统版本和录屏。
