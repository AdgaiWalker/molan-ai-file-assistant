# D1.12 手机端设置页设计

## 1. 定位

设置页服务两个目标：

- 帮用户把墨览设成 `.md` / `.json` 的默认打开工具。
- 清楚说明本地优先、云同步、隐私、缓存、数据导出的边界。

设置页不是账号中心，也不是云盘管理器。V1 无登录时仍应完整可用；V2 云端上线后，云同步默认关闭。

## 2. 入口

| 入口 | 行为 |
|---|---|
| 首页右上角更多 | 打开设置页 |
| 首次打开引导弹层 | 可跳到“默认打开指引” |
| 错误页“重新选择”旁 | 可进入打开方式排查 |
| 我的 / 个人页 | V1 可不做独立 tab，后续承接账号与同步 |

设置页使用普通页面或底部 Sheet 均可；V1 优先普通页面，便于放长说明。

## 3. 页面结构

| 区块 | 内容 | V1 行为 |
|---|---|---|
| 默认打开指引 | 微信、QQ、文件管理器里选择“其他应用/更多打开方式/墨览” | 展示步骤，提供“打开文件”按钮 |
| 文件与缓存 | 最近文档数量、提示词数量、临时转换文件说明 | 支持清理临时转换缓存；清理最近记录需二次确认 |
| 隐私说明 | 文件默认本地处理，不默认上传，不自动读取剪贴板 | 展示短说明与完整隐私页入口 |
| 数据导出 | 导出提示词库、最近文档索引、设置 | V1 导出 JSON 文件并走系统分享 |
| 云同步 | 云同步总开关、同步范围、账号状态 | V1 显示“未启用”；V2 默认关闭 |
| 关于 | 版本号、构建号、许可证、第三方组件 | 展示本地版本信息 |

## 4. 默认打开指引

指引必须覆盖国内高频来源：

| 来源 | 步骤 |
|---|---|
| 微信 | 长按/打开文件 → 右上角更多 → 其他应用打开 → 选择墨览 |
| QQ | 打开文件 → 更多 → 用其他应用打开 → 选择墨览 |
| 文件管理器 | 选中文件 → 打开方式 → 选择墨览 |
| 浏览器下载 | 下载完成 → 打开文件 → 选择墨览 |

异常提示：

- 系统不展示墨览：确认文件后缀是 `.md`、`.markdown` 或 `.json`。
- 微信/QQ 不给读取权限：先保存到本地，再从墨览“打开文件”进入。
- Android 需要重新选择默认应用：提示去系统应用设置清除默认打开。
- iOS 没有默认打开概念：提示通过分享面板选择墨览。

## 5. 云同步开关

V1 展示但不可开启：

- 状态：未启用。
- 文案：云同步将在 V2 提供，当前文件、提示词、最近记录均保存在本机。
- 操作：无账号登录，不弹外部授权。

V2 上线后的默认：

| 设置 | 默认 | 说明 |
|---|---|---|
| 云同步总开关 | 关闭 | 用户主动开启后才同步 |
| 同步提示词库 | 开启，但受总开关控制 | 只同步提示词元数据与正文 |
| 同步最近文档索引 | 开启，但受总开关控制 | 只同步文件名、类型、状态、时间，不上传文件内容 |
| 上传文件内容 | 关闭 | 只有“保存到云端/转给 AI 处理”才触发 |
| 使用移动网络同步 | 关闭 | 避免大文件误用流量 |

## 6. 隐私说明

设置页短说明必须直白：

- 阅读、复制、轻编辑、转换优先在本地完成。
- 文件内容不会默认上传。
- 剪贴板不会自动读取；只有用户点击“从剪贴板导入”才读取。
- 云同步开启后，默认只同步提示词、最近文档索引、收藏、状态等小数据。
- 删除数据应同时影响本地记录；V2 云端上线后提供云端删除说明。

完整隐私页至少包含：

- 会保存什么：提示词、最近文档索引、阅读位置、编辑草稿、转换临时文件。
- 不会默认保存什么：外部聊天记录、剪贴板历史、未主动打开的文件。
- 不会默认上传什么：原始文件内容、敏感字段、剪贴板内容。
- 用户能做什么：清缓存、清最近记录、导出数据、删除提示词、关闭云同步。

## 7. 缓存管理

| 数据 | 位置 | 清理策略 |
|---|---|---|
| 最近文档索引 | AsyncStorage / storage 层 | 可清空，二次确认 |
| 提示词库 | AsyncStorage / storage 层 | 不归入“清缓存”，需单独导出/删除 |
| 阅读位置 | storage/readPosition | 可清空 |
| 编辑草稿 | storage/draft | 可清空 |
| 转换临时文件 | Expo cache/document 目录 | 可清空，显示估算大小 |

实现要求：

- 组件不直接调用 AsyncStorage，后续实现应下沉到 `mobile/src/storage/`。
- 清理操作必须有成功/失败反馈。
- 清理失败不能让设置页白屏。

## 8. 数据导出

V1 导出一个本地 JSON 文件并打开系统分享：

```json
{
  "schemaVersion": 1,
  "exportedAt": "2026-07-04T00:00:00.000Z",
  "prompts": [],
  "recentDocs": [],
  "settings": {}
}
```

导出边界：

- 导出提示词正文，因为它是用户主动保存的数据。
- 最近文档只导出索引，不导出原文件内容。
- 不导出转换临时文件。
- 不导出系统权限状态。

## 9. 状态表

| 状态 | 展示 |
|---|---|
| 无数据 | 展示“本机暂无可导出数据” |
| 导出中 | 禁用导出按钮，展示进度文案 |
| 导出成功 | 打开系统分享面板 |
| 导出失败 | 展示错误原因和重试 |
| 云同步未启用 | 展示说明，不显示假登录状态 |
| 清理缓存失败 | 保留当前数据，提示稍后重试 |

## 10. 验收口径

- 用户能在设置页找到微信/QQ 默认打开指引。
- 用户能看到“文件不默认上传”的隐私说明。
- 云同步开关默认关闭，V1 不触发账号/网络依赖。
- 用户能清理临时缓存，不误删提示词库。
- 用户能导出提示词、最近文档索引、设置，且不导出原文件内容。
