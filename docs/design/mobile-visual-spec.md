# D1.14 手机端视觉规范

## 1. 视觉方向

墨览手机端是“AI 文件与提示词手机工作台”，视觉应像轻量系统工具，而不是内容社区或营销页。

关键词：

- 干净、直接、可扫读。
- 白底 / 深色系统底，蓝色主操作。
- 阅读优先，操作靠近底部，不遮挡正文。
- 国内微信/QQ 文件场景友好，少装饰，多反馈。

参考来源：

- 用户提供的手机端参考图：首页、Markdown 阅读、JSON 阅读、编辑页、提示词快贴、转换中心、AI 阅读卡片、云端收件箱。
- 当前代码：`mobile/src/theme.ts`、`mobile/App.tsx`、`mobile/src/components/*.tsx`。

## 2. 色彩

以 `mobile/src/theme.ts` 为唯一主题来源。

| 语义 | 日间 | 夜间 | 用途 |
|---|---|---|---|
| background | `#F7F8FA` | `#111113` | 页面底色 |
| surface | `#FFFFFF` | `#1C1C1E` | Sheet、列表、工具栏 |
| heading | `#0B0F19` | `#FFFFFF` | 标题 |
| text | `#1F2328` | `#F2F2F7` | 正文 |
| textSecondary | `#6B7280` | `#A1A1AA` | 辅助说明 |
| border | `#E5E7EB` | `#303034` | 分割线、轻边框 |
| link | `#007AFF` | `#0A84FF` | 主操作、选中态、链接 |
| codeBackground | `#F2F4F7` | `#242426` | 代码、搜索框、输入底 |
| codeText | `#B42318` | `#FF9F8A` | 代码/JSON 值强调 |

规则：

- 新组件不得写新的主色，必须使用 theme 语义色。
- 错误红可保留为语义色，后续应进入 theme，例如 `errorBg`、`errorText`。
- 不使用大面积渐变、装饰图形、彩色插画背景。
- 状态标签可使用 `link` 蓝、成功绿、警告橙、错误红，但正文区域不能变成彩色面板。

## 3. 字号

| 层级 | 字号 | 字重 | 用途 |
|---|---:|---|---|
| App 标识 / 首页大标题 | 32-34 | 800 | 首页“墨览” |
| 页面标题 | 18-20 | 700-800 | 阅读页、Sheet 标题 |
| 列表标题 | 15-17 | 700 | 最近文件、提示词条目 |
| 正文 | 16 | 400 | Markdown 正文 |
| 紧凑正文 | 13-14 | 400 | JSON 树、辅助说明、列表摘要 |
| 标签 / 元信息 | 11-12 | 600 | 文件类型、状态、快捷键 |
| 按钮文字 | 14-16 | 600-700 | 主按钮、次按钮 |

阅读字号使用 `FONT_SCALES`：

- 默认 `BASE_FONT_SIZE = 16`。
- 用户可在 0.85 / 1.0 / 1.15 / 1.3 / 1.5 间切换。
- 不按视口宽度缩放字体；小屏通过布局换行和密度调整解决。

## 4. 间距

| 场景 | 推荐值 |
|---|---:|
| 页面横向边距 | 16-20 |
| 紧凑小屏横向边距 | 14 |
| Sheet 内边距 | 20 |
| 卡片/列表项内边距 | 12-14 |
| 按钮垂直内边距 | 10-14 |
| 区块间距 | 14-20 |
| 列表项间距 | 8-10 |
| 输入框高度 | 38-44 |
| 底部操作区安全留白 | `max(14, insets.bottom + 14)` 以上 |

规则：

- 工具栏、底栏、Sheet 必须使用 `useSafeAreaInsets()`。
- 长正文底部必须预留底部操作栏高度，避免被复制/分享/转换按钮遮住。
- 固定格式控件如 JSON 行、提示词条目、底部按钮必须有稳定高度或最小高度，避免复制反馈导致跳动。

## 5. 圆角与边框

| 元素 | 圆角 |
|---|---:|
| 小按钮、输入框、状态标签 | 8 |
| 列表项、搜索框、文件卡片 | 8-10 |
| 工具卡片、导入框 | 10-12 |
| 底部 Sheet 顶角 | 18 |
| 浮层对话框 | 12 |

产品级规则：

- 普通卡片尽量不超过 12。
- Sheet 顶角可保留 18，用于系统底部面板感。
- 不做卡片套卡片；页面分区优先用间距、分割线和列表组织。
- 边框默认 1px `theme.border`，阴影少用。

## 6. 图标

图标风格：

- 线性、单色、24px 基准。
- 主操作可使用图标 + 文字。
- 工具按钮优先使用熟悉图标：文件夹、复制、搜索、收藏、分享、转换、设置、关闭。

实现建议：

- React Native 可统一引入 Expo Vector Icons 或 lucide-compatible 图标库；选定后不要混用多套。
- 没有图标库前，按钮文字可暂时保留，但 D/S 实现阶段新增工具按钮应优先图标化。
- 不使用 emoji 当功能图标。
- 不手写复杂 SVG 作为常规 UI 图标。

## 7. 按钮层级

| 层级 | 样式 | 用途 |
|---|---|---|
| Primary | `theme.link` 实底 + 白字 | 打开文件、复制、转换并分享、保存 |
| Secondary | surface/background + border + link/text | 分享、转换、导入、更多 |
| Tertiary | 纯文字或图标 | 关闭、清空、取消 |
| Destructive | 错误红文字或浅红底 | 删除、清空缓存 |
| Disabled | 降低透明度，禁用点击 | loading、非法 JSON、无内容 |

规则：

- 一个视图最多一个 Primary 主按钮。
- Sheet 底部可以有 Primary + Secondary 并列，但主按钮靠左或靠右需在同一类 Sheet 中保持一致。
- Loading 时按钮禁用，不能重复提交。

## 8. 布局模式

| 页面 | 模式 |
|---|---|
| 首页 | 顶部品牌 + 主按钮 + 最近文件 + 快捷入口 |
| 阅读页 | 全屏阅读 + 顶部轻工具栏 + 底部操作 Dock |
| JSON 页 | 顶部标题/复制操作 + 搜索 + 树视图 |
| 编辑页 | 顶部标题 + 编辑/预览切换 + 编辑器 + 底部保存操作 |
| 提示词快贴 | 底部 Sheet，搜索在顶部，列表可滚动 |
| 转换中心 | 底部 Sheet 或页面，任务队列优先 |
| 设置页 | 普通页面分区列表 |

原则：

- 首屏直接进入可用工具，不做营销 hero。
- 阅读内容不放在装饰卡片中。
- Sheet 用于短任务；长说明和设置用页面。
- 小屏宽度低于 380 时，按钮可换行或压缩，不允许文字溢出。

## 9. 安全区

| 平台 | 要求 |
|---|---|
| iOS 刘海屏 | 顶部栏加 `insets.top`，底部操作区加 `insets.bottom` |
| Android 手势导航 | 底部 Dock 和 Sheet 加安全区，避免贴底 |
| Android 三键导航 | 底部留白不小于 14 |
| 横屏 / 平板 | V1 以竖屏为主，平板保持最大内容宽度，不拉满长行 |

阅读页底部内容 padding 必须覆盖 Dock 高度；编辑页键盘弹出时底部按钮不遮输入区。

## 10. 浅深色适配

- 跟随系统 `userInterfaceStyle: automatic`。
- 所有文字、背景、边框、代码块走 theme。
- 半透明遮罩可使用 `rgba(0,0,0,0.28)`，夜间不额外加亮。
- 图片、文件图标需在浅深色都可见；图标资源应提供前景/单色版本。
- 截图验收必须覆盖日间和夜间核心阅读页。

## 11. Android / iOS 差异

| 差异 | Android | iOS |
|---|---|---|
| 打开方式 | intent filters 覆盖 content/file + md/json MIME/后缀 | Document Types + 分享面板 |
| 默认打开说明 | 允许清除默认应用 | 无默认打开概念，强调分享到墨览 |
| 返回 | 系统返回关闭 Sheet/弹层，再退出页面 | 顶部返回/关闭优先 |
| 文件图标 | adaptive icon 与 monochrome icon | App icon + 文档类型 |
| 悬浮快贴 | V1.5 申请悬浮窗权限 | 用键盘扩展/分享扩展方案替代 |

## 12. 资源规范

- App 名称：墨览。
- icon 路径：`mobile/assets/icon.png`、`mobile/assets/android-icon-foreground.png`、`mobile/assets/android-icon-background.png`、`mobile/assets/android-icon-monochrome.png`。
- 图标主题：Markdown 文件 + 蓝色连接点，匹配用户提供的 `.md` 图标方向。
- 发布截图必须覆盖：首页、Markdown 阅读、JSON 阅读、编辑、提示词、转换、AI 阅读卡片、云端收件箱。

- `EditSheet.tsx` 仍有硬编码错误红，后续应进 theme。
- 多处用户可见中文仍散在 JSX，后续按 AGENTS 文案集中规则收敛。
- 组件里还有 AsyncStorage 直用，后续按数据访问下沉规则处理。
- 首页和 Sheet 圆角存在 14/16/18 混用，后续实现按本规范收敛。

## 14. 验收口径

- 新增手机 UI 使用 `theme.ts` 语义色，不新增散落主色。
- 主路径按钮层级清楚，一个视图最多一个 Primary。
- 浅深色、Android/iOS 安全区都不遮挡正文和底部操作。
- 小屏下按钮文字不溢出。
- 图标不用 emoji，不手写临时装饰图形。
